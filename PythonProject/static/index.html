How is this estimate calculated? ＋

The form calls the original Python model through Flask. It fits the existing fare and market-share regressions using records that match your route and quarter, then runs your original final-fare calculation. The model uses all matching years, so selecting an earlier year is not a held-out backtest. This interface does not change or validate the original model’s accuracy.
